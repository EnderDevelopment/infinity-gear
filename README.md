# Infinity Gear

Infinity Gear is a Minecraft plugin that adds custom infinity items with special abilities. These items include a powerful pickaxe that breaks a 3x3 area of blocks, a fast axe, a shovel that digs quickly, a sword that deals high damage, a full set of armor that provides excellent protection, a bow that shoots arrows with great power, and a potion that grants speed, jump boost, and strength. The plugin is designed to enhance the gameplay experience by providing unique and powerful items.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server.

## Use

1. Use the command `/giveinfinityitems` to receive all infinity items.
2. Equip the infinity items to experience their special abilities:
   - **Infinity Pickaxe**: Breaks a 3x3 area of blocks.
   - **Infinity Axe**: Breaks blocks quickly.
   - **Infinity Shovel**: Digs quickly.
   - **Infinity Sword**: Deals high damage.
   - **Infinity Armor**: Provides excellent protection.
   - **Infinity Bow**: Shoots arrows with great power.
   - **Infinity Potion**: Grants speed, jump boost, and strength.
